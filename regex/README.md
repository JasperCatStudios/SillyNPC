# Worldkit regex scripts

The default-look regex scripts for Worldkit's trackers, one file per script in one folder per tracker: `bonds/`, `vitals/`, `inventory/` and `internal-states/`. They dress the blocks the trackers write under each reply and keep them out of old prompts (the context savers).

Import them in SillyTavern (Extensions, Regex, the import arrow) and keep them enabled, or use the **Content Kit** tab in the Worldkit menu, which fetches the Worldkit-Content repository and imports them by group. The full list, what each one matches, the context savers and the three extra looks (Cozy Parchment, Persona HUD, Tactical Glass Telemetry) are described in `regex/README.md` of the Worldkit-Content repository: https://github.com/JasperCatStudios/Worldkit-Content

These are the scripts of the **Default - Freaky Frankenstein** look. Worldkit applies them itself, so nothing needs importing (regexes you have imported that style a block are used instead). They are generated by `tools/build-default-regexes.mjs` into `src/default-regexes.js`. The Look choice at the top of each tracker's menu can also pick Cozy Parchment, Persona HUD or Tactical Glass, which are drawn the same way.
